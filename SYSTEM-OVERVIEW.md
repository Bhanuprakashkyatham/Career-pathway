## 💡 **Pro Tips**

### **1. Learning Hub is Your Primary Tool**
- Use it for 80% of learning
- Only use Time Logger for activities you can't add to Hub
- Everything trackable should be in Hub

### **2. Keep Learning Hub Clean**

- Archive old lessons
- Export before major changes

- Backup every Sunday
- Name files by date: `roadmap-2026-05-20.json`
