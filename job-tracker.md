## Interview Preparation Checklist

### Technical Prep
- [ ] Java core concepts (Collections, Multithreading, Exception Handling)
- [ ] Hibernate (Session, Transactions, Caching, Lazy Loading)
- [ ] Spring Boot basics (Annotations, Dependency Injection, REST APIs)
- [ ] React fundamentals (Hooks, State Management, Props)
- [ ] Database (SQL queries, Joins, Normalization, Indexing)
- [ ] REST API design principles
- [ ] DSA basics (Arrays, Strings, LinkedList, Recursion)

### Behavioral Prep
- [ ] Self introduction (practiced 10+ times)
- [ ] Why leaving current company?
- [ ] Biggest achievement
- [ ] Challenges faced and overcome
- [ ] Team conflict resolution
- [ ] Career goals (5 years)

### HR Round Prep
- [ ] Salary expectations (8-15 LPA)
- [ ] Notice period (negotiable)
- [ ] Relocation willingness
- [ ] Strengths and weaknesses
